High

H1Compose mounts a git-ignored file that a fresh clone lacks

AD-14 (spine line 206), Structural Seed · NFR-1, SM-4, Glossary "Test switch", DR-5

The examiner's stack mounts config/test-switches.toml. On a fresh clone Docker either creates a directory there (backend fails at startup, stray folder left) or refuses to start.

Fix: mount the ./config directory read-only; BP_TEST_SWITCHES defaults to test-switches.toml inside it; anything that is not a regular file counts as missing. The e2e fixture mounts its own temp dir through one compose variable. README: edit, then docker compose restart backend.

H2HT-2 expects headers on Caddy's automatic redirect

AD-27 Headers (line 353), HT-2 (line 358) · FR-24

The automatic HTTP→HTTPS redirect is served by a separate Caddy server and carries none of the site's headers (verified by tech-currency; correct per RFC 6797 §7.2).

Fix: drop "including Caddy's own redirects"; HT-2 tests a page, an API 404, a static asset and a Caddy-generated HTTPS error (backend stopped). HT-1 checks only Location.
